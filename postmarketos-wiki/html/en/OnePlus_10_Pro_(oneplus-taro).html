How to enter flash mode

1. Enable Developer Options: Settings -> About Phone -> Click on "Build number" 9 times
2. OEM unlocking: System -> Developer options -> Enable "OEM unlocking"
3. Unlock the bootloader: adb reboot bootloader -> fastboot logo should appear
4. Finally: open terminal -> fastboot flashing unlock

Installation

1. downloading kernel source

git clone https://github.com/Xlie-Electronic-Customs/linux.git
cd linux

2. building kernel

make O=output ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- -j$(nproc) sm8450_defconfig
make O=output ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- -j$(nproc)
make O=output ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- INSTALL_MOD_PATH=out-modules modules_install

cd ..

3. building initramfs and rootfs images

curl -O 'https://ca.us.mirror.archlinuxarm.org/os/ArchLinuxARM-aarch64-latest.tar.gz'

# building rootfs
truncate -s 4G root.img
mkfs.ext4 root.img -L root
mkdir root
sudo mount root.img root
sudo tar -xzvf ArchLinuxARM-aarch64-latest.tar.gz -C root
sudo cp -r linux/output/out-modules/lib/modules/* root/lib/modules/

# building initramfs
cp root/boot/initramfs-linux.img .
dd if=initramfs-linux.img of=initramfs-header count=10240 bs=1
dd if=initramfs-linux.img of=initramfs-linux.gz skip=10240 bs=1
gzip -d initramfs-linux.gz
mkdir initramfs
cd initramfs
sudo cpio -iv < ../initramfs-linux

sudo rm -r lib/modules/*
sudo cp -r ../linux/output/out-modules/lib/modules/* lib/modules/
m=$(ls lib/modules)
sudo rm -r lib/modules/$m/kernel/*
sudo mkdir lib/modules/$m/kernel/drivers/
sudo cp -r ../linux/output/out-modules/lib/modules/$m/kernel/drivers/clk lib/modules/$m/kernel/drivers/
sudo cp -r ../linux/output/out-modules/lib/modules/$m/kernel/drivers/soc lib/modules/$m/kernel/drivers/
sudo cp -r ../linux/output/out-modules/lib/modules/$m/kernel/drivers/phy lib/modules/$m/kernel/drivers/
sudo cp -r ../linux/output/out-modules/lib/modules/$m/kernel/drivers/ufs lib/modules/$m/kernel/drivers/
sudo cp -r ../linux/output/out-modules/lib/modules/$m/kernel/drivers/usb lib/modules/$m/kernel/drivers/

sudo find . -print0 | cpio --null -ov --format=newc | gzip -9 > ../initramfs.gz
cd ..
cat initramfs-header initramfs.gz > initramfs-linux.img

# unmount root.img
sudo umount root

3. building vbmeta, boot and vendor_boot images 

avbtool make_vbmeta_image --output vbmeta.img --flags 2
mkbootimg --header_version 4 --vendor_boot vendor_boot.img --dtb linux/output/arch/arm64/boot/dts/qcom/sm8450-oneplus-taro.dtb --pagesize 4096
mkbootimg --kernel linux/output/arch/arm64/boot/Image.gz --ramdisk initramfs-linux.img --header_version 4 --pagesize 4096 --os_version 12.0.0 --os_patch_level 2025-12-00 --cmdline "console=tty0 root=/dev/sda14 rootwait rw" -o boot.img
img2simg root.img sparse_root.img

4. flashing

fastboot erase dtbo
fastboot flash vbmeta vbmeta.img
fastboot flash vbmeta_vendor vbmeta.img
fastboot flash vbmeta_system vbmeta.img
fastboot flash vendor_boot vendor_boot.img
fastboot erase userdata
fastboot flash userdata sparse_root.img
fastboot flash boot boot.img

fastboot reboot

Additional info

USB OTG

The USB C UCSI switching beetwen host and device mode works when adsp remoteproc up. The power in host mode is broken so without external power host mode will be not work. Device mode works well! Both of usb modes works well in super-speed (5 Gbit/s) speed mode

Battery

Percentage shows when adsp remoteproc up, don`t charging
