Architecture

The platform, codenamed "Hamoa", utilizes a heterogeneous compute fabric managed by a sophisticated internal Network-on-Chip (NoC).

Silicon and Packaging

Process Node: TSMC 4nm FinFET (N4 family).

Packaging: Primarily FC-BGA (BGA 2073), with support for Package-on-Package (PoP) in ultra-compact designs.

TDP Scalability: 12W (fanless) to 80W (active-cooled workstations).

CPU: Qualcomm Oryon

The Oryon CPU is a custom 64-bit ARMv8.7-A+ compliant processor organized into three clusters of four cores (12 total cores).

Front-End: 8-wide decode engine with a 13-cycle branch mispredict penalty.

Pipeline: 600+ entry Re-Order Buffer (ROB) and ~400 entry Physical Register File (PRF).

Execution Units:

  • 6-wide Integer Execution Unit (IXU).
  • 4-wide Vector Execution Unit (VXU) (128-bit).
  • 4-wide Load/Store Unit (LSU) supporting 200+ in-flight operations.

Cache Hierarchy:

  • L1 Cache: 192 KB Instruction / 96 KB Data per core.
  • L2 Cache: 12 MB shared per 4-core cluster (36 MB total).
  • System Level Cache (SLC): 6 MB shared across the SoC.

GPU: Adreno X1-85

Performance: Up to 4.6 TFLOPS.

Shaders: 1,536 unified shader units clocked up to 1.5 GHz.

APIs: DirectX 12, Vulkan 1.3, OpenCL 3.0.

FlexRender: Supports tile-based rendering (TBR) and direct rendering modes.

NPU: Hexagon AI Engine

Performance: 45 TOPS (INT8).

Architecture: Fused VLIW architecture combining scalar, vector, and tensor accelerators.

Sensing Hub: Includes dual Micro NPUs for low-power "always-sensing" features (presence detection, facial recognition).

Subsystems

Visual Subsystem

Adreno VPU: Hardware encoding/decoding for H.264, HEVC, and AV1. (4K120 dec / 4K60 enc).

Adreno DPU: Supports internal eDP v1.4b (4K120) and up to three external 4K60 displays via DP 1.4a.

Connectivity

Modem: Integrated Snapdragon X65 5G (up to 10 Gbps download).

Local: FastConnect 7800 (Wi-Fi 7, Wi-Fi 6E, Bluetooth 5.4).

Memory & I/O

Memory Type: LPDDR5x-8448.

Bus Width: 128-bit (8 x 16-bit channels).

Peak Bandwidth: 135.2 GB/s.

Expansion:

  • 12 lanes of PCIe Gen 4 (NVMe).
  • 4 lanes of PCIe Gen 3 (WLAN/BT).
  • 3 x USB4 (40 Gbps) with DP Alt Mode.

Security

The platform employs a multi-layered security model anchored by the Qualcomm Secure Processing Unit (SPU).

Microsoft Pluton: Integrated directly into the SPU to provide a hardware-isolated TPM 2.0.

TrustZone: ARM-based TEE for biometric matching and DRM.

Memory Encryption: Supports full RAM encryption to mitigate physical tampering.

Linux Support

Linux support is coordinated through upstreaming efforts between Qualcomm and Linaro.

Mainline Kernel Status

Kernel 6.8/6.9: Support for pinctrl, GCC/RPMHCC clocks, SMMU, and PCIe NVMe.

Kernel 6.11/6.12 (Targeted): Adreno X1-85 (MSM DRM) graphics, DPU/eDP display, and Aqstic audio drivers.

Technical Challenges

Device Trees: Current reliance on Device Tree Blobs (DTB) rather than full ACPI maturity for Linux.

Firmware: Requires specific firmware loaders for proprietary blocks (NPU/GPU).
